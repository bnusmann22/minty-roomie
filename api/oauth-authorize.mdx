The Roomie OAuth server enables third-party housing platforms to authenticate students using their verified Roomie identity — the "Sign in with Roomie ID" button. This endpoint begins the Authorization Code flow: you redirect the user's browser to this URL with your `client_id` and requested scopes. The user logs in on Roomie's hosted consent page, approves access, and is redirected back to your `redirect_uri` with a short-lived authorization code.

This is a browser redirect — not a server-to-server API call. Construct the URL and redirect your user to it.

## GET /api/oauth/authorize

### Base URL

```
https://api.roomie.app/api/oauth/authorize
```

### Query Parameters

<ParamField query="client_id" type="string" required>
  Your housing platform's OAuth client ID, issued when your platform was registered with Roomie. Each housing platform has a unique `client_id`.
</ParamField>

<ParamField query="redirect_uri" type="string" required>
  The URL on your platform where Roomie should redirect the user after authorization. This must exactly match one of the `redirect_uris` registered for your `client_id` on the Roomie platform — no trailing slashes, no query parameters.
</ParamField>

<ParamField query="scope" type="string" required>
  A space-separated list of permission scopes you are requesting. The user will see these scopes on the consent screen.

  | Scope | Access Granted |
  |-------|---------------|
  | `profile:read` | Basic profile info: display name, Roomie ID, university |
  | `verification:read` | Student verification status and identity badge |
  | `network:read` | Active roommate partner info and connection network size |

  Example: `profile:read verification:read`
</ParamField>

<ParamField query="state" type="string" required>
  A random, unguessable string generated by your server for this authorization attempt. Roomie echoes it back unchanged in the redirect. Always verify it matches before exchanging the code — this prevents CSRF attacks.
</ParamField>

<ParamField query="response_type" type="string">
  Must be `"code"`. Only the Authorization Code grant is supported. Defaults to `"code"` if omitted.
</ParamField>

### Full Authorization URL Example

```
https://api.roomie.app/api/oauth/authorize
  ?client_id=roomie_client_abc123
  &redirect_uri=https%3A%2F%2Fyourplatform.ng%2Fauth%2Fcallback
  &scope=profile%3Aread%20verification%3Aread%20network%3Aread
  &state=xK9mP3qRtZ7vWnL2
  &response_type=code
```

### Constructing the URL in Code

<CodeGroup>
```typescript TypeScript
const authUrl = new URL("https://api.roomie.app/api/oauth/authorize");

authUrl.searchParams.set("client_id", "roomie_client_abc123");
authUrl.searchParams.set(
  "redirect_uri",
  "https://yourplatform.ng/auth/callback"
);
authUrl.searchParams.set("scope", "profile:read verification:read network:read");
authUrl.searchParams.set("state", generateSecureRandomString());
authUrl.searchParams.set("response_type", "code");

// Redirect the user
window.location.href = authUrl.toString();
```

```python Python
from urllib.parse import urlencode
import secrets

params = {
    "client_id": "roomie_client_abc123",
    "redirect_uri": "https://yourplatform.ng/auth/callback",
    "scope": "profile:read verification:read network:read",
    "state": secrets.token_urlsafe(16),
    "response_type": "code",
}

auth_url = f"https://api.roomie.app/api/oauth/authorize?{urlencode(params)}"
# Redirect user to auth_url
```
</CodeGroup>

### User Experience on Roomie's Consent Screen

After being redirected to Roomie:

1. If not logged in, the user is shown the Roomie login form.
2. After authentication, the user sees a consent screen listing your platform name, logo, and the requested scopes.
3. The user approves or denies access.

### Successful Redirect (User Approved)

Roomie redirects to your `redirect_uri` with the authorization code and echoed state:

```
https://yourplatform.ng/auth/callback
  ?code=AUTH_CODE_XYZ123abc
  &state=xK9mP3qRtZ7vWnL2
```

<ResponseField name="code" type="string">
  A short-lived, single-use authorization code. Valid for **5 minutes**. Pass this to `POST /api/oauth/token` immediately to exchange it for an access token.
</ResponseField>

<ResponseField name="state" type="string">
  The same value you passed in the `state` parameter. **Always verify this matches before proceeding** to protect against CSRF.
</ResponseField>

### Denied Redirect (User Rejected)

```
https://yourplatform.ng/auth/callback
  ?error=access_denied
  &error_description=The+user+denied+access
  &state=xK9mP3qRtZ7vWnL2
```

## Complete SSO Flow Diagram

```
Your Platform                  User Browser              Roomie OAuth Server
      │                              │                           │
      │── Build authorize URL ──────►│                           │
      │                              │── GET /api/oauth/authorize►│
      │                              │                           │
      │                              │◄── Roomie consent page ───│
      │                              │                           │
      │                              │── User approves ─────────►│
      │                              │                           │
      │                              │◄── Redirect to your URI ──│
      │                              │    ?code=XYZ&state=ABC    │
      │◄── code=XYZ arrives ─────────│                           │
      │                              │                           │
      │──── POST /api/oauth/token ───────────────────────────────►│
      │     (server-to-server)                                   │
      │◄─── access_token ────────────────────────────────────────│
      │                              │                           │
      │──── GET /api/oauth/userinfo ─────────────────────────────►│
      │◄─── verified profile ────────────────────────────────────│
```

<Warning>
  Authorization codes are **single-use and expire in 5 minutes**. Do not reuse codes or attempt to cache them. After a successful token exchange, the code is invalidated immediately.
</Warning>

## Error Reference

| Error | Cause |
|-------|-------|
| `invalid_client` | `client_id` is not registered |
| `invalid_redirect_uri` | `redirect_uri` does not match a registered URI for this client |
| `invalid_scope` | One or more requested scopes are not allowed for this client |
| `access_denied` | User declined the authorization request |
