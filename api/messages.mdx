Roomie's messaging system is the communication layer for matched roommates. Each connection has its own private chat thread where students can discuss compatibility, coordinate move-in logistics, share media, and receive system-generated updates like agreement proposals or bill split notifications. All messages are scoped to a connection — you cannot message a user you are not connected to.

## GET /v1/messages

Retrieve the message history for a specific connection thread. Messages are returned in reverse-chronological order (newest first) and support cursor-based pagination for long conversations.

### Authentication

Requires a valid Bearer token. The authenticated user must be a participant of the connection.

### Query Parameters

<ParamField query="connection_id" type="string" required>
  UUID of the connection whose message thread you want to retrieve.
</ParamField>

<ParamField query="limit" type="integer">
  Number of messages to return per page. Defaults to `20`, maximum `100`.
</ParamField>

<ParamField query="before" type="string">
  A message UUID. Returns only messages created before this message, enabling backwards pagination.
</ParamField>

<CodeGroup>
```bash cURL
curl "https://api.roomie.app/v1/messages?connection_id=a1b2c3d4-e5f6-7890-abcd-ef1234567890" \
  -H "Authorization: Bearer <your_token>"
```

```bash Paginate backwards (cURL)
curl "https://api.roomie.app/v1/messages?connection_id=a1b2c3d4-e5f6-7890-abcd-ef1234567890&before=msg-uuid-abc&limit=20" \
  -H "Authorization: Bearer <your_token>"
```

```typescript fetch
const params = new URLSearchParams({
  connection_id: "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  limit: "20",
});

const res = await fetch(`https://api.roomie.app/v1/messages?${params}`, {
  headers: { Authorization: `Bearer ${access_token}` },
});

const messages = await res.json();
```
</CodeGroup>

  Array of message objects ordered newest-first.
</ResponseField>

<ResponseField name="data[].sender" type="object | null">

  CDN URL of an attached image or file, if any.

<ResponseField name="next_cursor" type="string | null">

## POST /v1/messages

Send a message to the connection thread. Supports plain text and optional media attachments.

### Authentication

Requires a valid Bearer token. The authenticated user must be a participant of the connection.

### Request Body

<ParamField body="connection_id" type="string" required>
  UUID of the connection thread to send the message to.
</ParamField>

<ParamField body="content" type="string" required>
  The text body of the message. Maximum 2,000 characters.
</ParamField>

<ParamField body="media_url" type="string">
  Optional CDN URL for an image or document attachment. Upload the file to a CDN or object storage first, then pass the public URL here.
</ParamField>

<CodeGroup>
```bash Text message (cURL)
curl -X POST https://api.roomie.app/v1/messages \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "connection_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "content": "Are you free to check out the hostel this weekend?"
  }'
```

```bash Message with media (cURL)
curl -X POST https://api.roomie.app/v1/messages \
  -H "Authorization: Bearer <your_token>" \
  -H "Content-Type: application/json" \
  -d '{
    "connection_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "content": "Here is a photo of the room I found",
    "media_url": "https://cdn.roomie.app/uploads/room-photo-xyz.jpg"
  }'
```

```typescript fetch
const res = await fetch("https://api.roomie.app/v1/messages", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${access_token}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    connection_id: "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    content: "Are you free to check out the hostel this weekend?",
  }),
});

const message = await res.json();
```
</CodeGroup>

### Response `201 Created`

```json
{
  "id": "msg-uuid-004",
  "connection_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "sender": {
    "id": "3f7e2d1a-bc44-4e91-b9f3-123456789abc",
    "username": "adaeze_okafor"
  },
  "content": "Are you free to check out the hostel this weekend?",
  "media_url": null,
  "type": "TEXT",
  "created_at": "2025-11-14T15:00:00Z"
}
```

<Note>
  Message delivery to connected clients is handled via WebSocket push in real-time. This REST endpoint persists the message and triggers the push — it does not establish a WebSocket connection itself.
</Note>

## Error Reference

| Status | Cause |
|--------|-------|
| `400 Bad Request` | `content` is empty or exceeds 2,000 characters |
| `401 Unauthorized` | Missing or invalid Bearer token |
| `403 Forbidden` | Authenticated user is not a participant of the connection |
| `404 Not Found` | Connection with `connection_id` does not exist |
